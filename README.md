# Методолог — Конструктор образовательных программ

Чат-приложение с AI-агентами для создания образовательных программ.

## Деплой на Vercel (5 минут)

### 1. Загрузи код на GitHub
- Создай новый репозиторий на github.com
- Загрузи все файлы из этой папки

### 2. Подключи к Vercel
- Зайди на vercel.com
- Нажми "New Project"
- Выбери свой репозиторий с GitHub
- Нажми "Deploy"

### 3. Добавь API ключ
- В Vercel → Settings → Environment Variables
- Добавь переменную:
  - Name: `ANTHROPIC_API_KEY`
  - Value: `sk-ant-...` (твой ключ с console.anthropic.com)
- Нажми "Save"
- Нажми "Redeploy"

### 4. Готово!
Vercel даст ссылку типа `your-app.vercel.app` — отправь команде.

## Структура агентов

1. **Интервьюер** — собирает бриф по 6 вопросам
2. **Методолог** — составляет программу (до 3 итераций)
3. **Редактор** — готовит ТЗ на доработку при отклонении
4. **Составитель кейсов** — пишет практические задания
5. **Финал** — программу можно скачать как .md файл
